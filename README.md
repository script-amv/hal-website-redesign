# HAL website redesign

An unofficial HTML, CSS, and JavaScript redesign of the HAL Senmon Gakko website. This is an independent practice project.

## Run locally

Open `index.html` in a browser, or serve this directory with a local static HTTP server. No package installation or build step is required.

## Repository index

- [index.html](index.html): page markup.
- [styles.css](styles.css): page styling.
- [script.js](script.js): browser interactions.
- Root image, SVG, and design assets support the page.
